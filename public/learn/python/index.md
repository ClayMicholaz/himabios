![Python](/python-logo.png)

- **Syntax dan struktur dasar Python**
- **Variabel dan tipe data**
- **Operator dan operasi matematika**
- **Input dan output**

### **Struktur Kontrol**

- **Conditional statements (if, elif, else)**
- **Loops (for, while)**

### **Struktur Data**

- **Sets dan operations**

## 💡 Tips Belajar Python

1. **Practice Makes Perfect**: Koding setiap hari, meski cuma 15 menit
2. **Build Projects**: Buat project kecil untuk mengaplikasikan ilmu
3. **Read Others' Code**: Baca kode orang lain untuk belajar best practices
4. **Join Community**: Bergabung dengan komunitas Python Indonesia
