# Tipe Data

Tipe Data Python Dasar

| Tipe Data  | Deskripsi                                                                                   | Contoh                                                                                            |
| :--------- | :------------------------------------------------------------------------------------------ | :------------------------------------------------------------------------------------------------ |
| Angka      | Tipe data untuk angka.                                                                      | int (bilangan bulat: `3`), float (bilangan desimal: `3,5`), complex (bilangan kompleks: `3 + 2i`) |
| Boolean    | Menampilkan nilai logika. Hanya memiliki dua nilai: `True` atau `False`.                    | `True`, `False`                                                                                   |
| String     | Sekumpulan karakter (teks) yang diapit oleh tanda kutip tunggal (`' '`) atau ganda (`" "`). | `'halo dunia'`, `"123"`                                                                           |
| List       | Kumpulan data yang terurut dan dapat diubah. Diapit oleh kurung siku `[]`.                  | `['apel', 'pisang', 'ceri'], [1, 2, 3]`                                                           |
| Tuple      | Kumpulan data yang terurut dan tidak dapat diubah. Diapit oleh kurung biasa `()`.           | `('apel', 'pisang', 'ceri'), (1, 2, 3)`                                                           |
| Dictionary | Kumpulan pasangan key-value yang tidak terurut. Diapit oleh kurung kurawal `{}`.            | `{'nama': 'Budi', 'umur': 25}`                                                                    |
