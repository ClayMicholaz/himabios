# Operasi Perbandingan

Comparison Operator adalah simbol dalam pemrograman yang digunakan untuk membandingkan dua nilai. Hasil dari perbandingan ini selalu berupa nilai Boolean, yaitu True jika perbandingan itu benar, atau False jika salah.

Operator ini sangat penting dalam membuat keputusan dalam program, seperti pada struktur kontrol (if, elif, else). Mereka memungkinkan program untuk bertindak berbeda tergantung pada kondisi tertentu.

> Contoh angka a = 5 dan b = 8

| Operator | Nama Operator                     |  Contoh  | Hasil                                 | Penjelasan                              |
| :------- | :-------------------------------- | :------: | ------------------------------------- | --------------------------------------- |
| `==`     | Sama dengan                       | `a == b` | <span style="color:red">False</span>  | Memeriksa apakah sama.                  |
| `!=`     | Tidak sama dengan                 | `a != b` | <span style="color:green">True</span> | Memeriksa apakah tidak sama.            |
| `>`      | Lebih besar dari                  | `a > b`  | <span style="color:red">False</span>  | Memeriksa apakah lebih besar.           |
| `<`      | Lebih kecil dari                  | `a < b`  | <span style="color:green">True</span> | Memeriksa apakah lebih kecil            |
| `>=`     | Lebih besar dari atau sama dengan | `a >= b` | <span style="color:red">False</span>  | Memeriksa apakah lebih besar atau sama. |
| `<=`     | Lebih kecil dari atau sama dengan | `a <= b` | <span style="color:green">True</span> | Memeriksa apakah lebih kecil atau sama. |
