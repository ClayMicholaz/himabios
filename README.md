## Tentang HIMA BIOS UBM Ancol

**HIMA BIOS UBM Ancol** adalah Himpunan Mahasiswa Informatika Universitas Bunda Mulia yang berlokasi di Jakarta Utara, Ancol. Kami berkomitmen untuk:

- 📚 Menyediakan **platform belajar programming gratis**
- 🤝 Membangun **komunitas programmer** yang solid
- 🎯 Mengembangkan **keterampilan coding** mahasiswa
- 🚀 Memfasilitasi **pengembangan teknologi** dan inovasi

### Fitur Utama

- **📖 Materi Programming**: Algoritma, struktur data, dan tutorial coding
- **🎓 Pengumuman Seleksi**: Sistem pengumuman anggota baru yang interaktif
- **📱 Responsive Design**: Optimized untuk desktop dan mobile
- **🌙 Dark Mode**: Mendukung tema gelap dan terang
- **⚡ Fast Loading**: Dibangun dengan Next.js untuk performa optimal

## Tech Stack

- **Frontend**: Next.js 15.5.3 + TypeScript
- **Styling**: Tailwind CSS + Custom Design System
- **Deployment**: Vercel
- **SEO**: Optimized meta tags, structured data, sitemap
- **PWA**: Progressive Web App support

## Getting Started

### Prerequisites

- Node.js 18.17 atau lebih baru
- npm, yarn, atau pnpm

### Installation

```bash
# Clone repository
git clone https://github.com/KwikAndreas/himabios.git
cd himabios

# Install dependencies
npm install
# atau
yarn install
# atau
pnpm install

# Run development server
npm run dev
# atau
yarn dev
# atau
pnpm dev
```

## Struktur Project

